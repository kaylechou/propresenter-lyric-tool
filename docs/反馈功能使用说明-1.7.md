# 反馈功能使用说明（1.7）

## 入口

- 打开工具内帮助面板，点“反馈”。
- 或在主界面点“反馈”按钮。
- 两个入口打开的是同一个反馈表单。

## 表单

- 内容必填，最多 1000 字。
- 类型三选一：问题、建议、其他。
- 联系方式选填。
- 工具版本自动带上，不用手动填。
- 必须写文字内容。
- 只发图片、不写文字，无法提交。

## 截图

- 可以文件选择、粘贴、拖拽添加截图。
- 提交前可以看到缩略图。
- 不想要的单张可以单独删除。
- 最多 3 张。
- 单张原图不超过 5MB。
- 提交总包不超过 8MB。
- 格式支持 PNG、JPEG、WebP。
- 超出限制会提示重选。

## 提交后查状态

- 提交成功后会得到一个反馈编号。
- 记下这个编号。
- 打开“我的反馈”，输入编号查询。
- 不用登录就能查。
- 可以看到当前状态和回执。

## 五种状态含义

- 待处理：已收到，还没开始看。
- 知悉：已看到，已记下。
- 处理中：正在处理。
- 已处理：已经处理完。
- 不做：这次不做。

## 隐私提示

- 提交前先检查内容。
- 不要写密钥、账号等私密信息。
- 反馈默认会公开显示。
- 不想公开的内容不要提交。
- 联系方式只用于联系你，不用必填。
