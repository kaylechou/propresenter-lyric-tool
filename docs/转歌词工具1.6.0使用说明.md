# Pro Pages tool 1.6.0 使用说明

## 1.6.0 新增

### 1. 歌库分享机制

- 歌库里选歌，生成分享清单。
- 分享前先过版权确认，确认后才发出。
- 分享可作废，作废后对方不再能用这份分享。
- 分享可转发，转发时同样提示版权确认。
- 接收方导入时先预览，确认后再进歌库。

### 2. 去重与同步：歌词为主，歌名辅

- 去重以歌词本身为准，歌词相同即视为同一首。
- 同步索引新增歌词哈希，歌词一变，哈希跟着变。
- 同一首歌，歌词相同、歌名或歌手不同时，同步歌名与歌手。
- 不同歌曲，歌词不同时，跳过不覆盖。
- 导入时跳过的行，若歌名不同，同时显示两个歌名。
- 本地与同步之间，同样按歌词去重。
- 冲突时不单方面覆盖，保留双方内容。

### 3. 留置修复 7 项

- 单字标签修复：个别单字标签在语言切换时卡住，现已修好。
- 歌名页留置 3 项修复：文件夹导出按歌名页开关出歌名页；库导出歌名页条目带完整样式；从歌库载入歌曲时，歌名页显隐开关正确重置。
- 首次同步失败回退：首次同步推不上去时，按回退口径处理，不丢本地歌。
- 加载失败有界重试：加载失败时有限次数重试，不无限等待。
- 导入双显示扩展：导入跳过行歌名不同时，双歌名显示覆盖更多情形。
- 拉取提示双段：拉取结果提示分两段写清，先说结果，再说原因。
- 导出提示五语化：导出完成提示按当前界面语言显示。

### 4. 歌名页默认自动生成

- 歌名页开关默认开。
- 新歌自动建歌名页，不用手动选生成。
- 关掉开关可不贴歌名页，选择保留。
- 自动补建的歌名页，只写歌名与歌手。
- 译文与拼音不编造，没有就不写。
- 文件夹导出时，是否贴歌名页以该开关为准。

### 5. 液态玻璃界面

- 工具界面换为液态玻璃风格。
- 明亮浅色底，高对比可读。
- 只改工具界面样式层。
- 歌词渲染与导出结果不变。

### 6. K 全玻璃新图标

- 1.6.0 起，软件图标换为 K 全玻璃版。
- 明亮浅色，粗壮大图形，桌面上一眼能认出。
- 图标只换外观，功能不变。

### 7. 1.5.0 之后的其他变化

- 逐字、逐句、逐段样式：每段、每句、每字可设字体、字号、颜色、加粗。
- 主题样式：24 个主题样式可自由调用，拆页后每页可指定。
- .proTheme 导入：只导文字样式，不导位置、背景、形状。
- 主题文件一起导出：导出文本文件时，本文档各页用到的主题文件一并下载。
- .pptx 导出：导出四选一，txt、.pro、.pro6、.pptx。
- 歌库：保存、分类、导出导入共享，库内按歌名与歌词内容搜索。
- 歌库多级分类：分类可多级，可编辑、添加、删除。
- 歌库同步：手动同步，索引搜索拉取，冲突保留双方，删除不同步。
- 歌库文件夹导出：按多级分类层级建文件夹，歌曲放入对应文件夹。
- 界面五语：简体、繁体、英文、日文、韩文，静态文案全覆盖。
- 搜索简繁变体：繁体搜简体歌名、简体搜繁体歌名均可命中。

## 核心流程

- 导入 → 清理 → 拆页 → 字体 → 段落 → 样式 → 翻译 / 拼音 → 分页预览 → 歌库 → 导出 txt / .pro / .pro6 / .pptx。
- 搜索页签：填歌名搜歌词，选候选进校对。
- 云端识别：复杂谱面用大模型识谱，识别结果进第 2 步校对。

## 第 1 步 导入

- 粘贴歌词：一行一句，段落间空一行，段落名单独一行，点「载入并拆页」。
- 字幕文件 .srt / .lrc / .vtt / .ass：自动去时间轴和序号。
- 歌谱图片 / PDF：选识别引擎后点识别，自动整理进第 2 步。
- 全网搜索页签：填歌名，可填歌手、专辑。
- 多路并行搜索，候选并行拉取。
- 点卡片「查看并编辑」看全文改文字，点「生成分页预览」拆页。
- 结果自带括号拼音按音节去掉，英文保留。
- 点「换一换」再搜一批。
- 候选须与歌名或歌词句相关才列出。
- 搜不到不编造。

### 识别引擎

- 快速识别：本机，中英日韩等常用语言。
- 增强识别：本机，中文小字更准；网页版首次需联网下载模型，桌面版已内置。
- 云端识别：大模型识谱，复杂谱面用。
- 模型按提供方分组：Gemini、OpenAI、Claude、智谱、通义、硅基流动、DeepSeek、Kimi、豆包。
- Gemini 默认 gemini-3.5-flash-lite。
- 密钥按提供方分别保存，只存在本机设备。
- 识别出的歌名、歌手自动填入第 2 步空框，已有内容不覆盖。
- 云端没跑起来，按提示改用本地识别。

## 第 2 步 校对

- 对照原谱改错字，空行分段，段落名单独一行。
- 「谱面过滤＋分组」：去和弦行、简谱数字行、谱头信息，按标记或重复段分段。
- 「智能整理结构」：字幕用，去时间轴、序号、空行，重复段标副歌。
- 「智能清理」：只去汉字间空格、汉字与中文标点相邻空格；「去除标点」默认开。
- 「去括号拼音」：默认开，括号里符合拼音音节才去，英文不动。
- 「转简体 / 转繁体」：只转正文，歌名、歌手框不转。

## 第 3 步 拆页与样式

- 每页容量按行数或字数，默认 24 字，整行装页不拆行。
- 分段方式：按段落拆页或连续拆页。
- 段落名作标签或正文。
- 样式可调：字体、粗细、对齐、文字颜色、段落标签颜色。
- 行高（倍）、行距（%）、段落间距（pt）、字符间距（pt）。
- 边距左 / 上 / 右 / 下。
- 描边（开关 / 宽度 / 颜色）。
- 阴影（开关 / 角度 / 偏移 / 模糊 / 透明度 / 颜色）。
- 字号可直接输入磅值，如 130pt。
- 磅值与百分比滑杆同步，60pt = 100%。
- 改动同步到分页预览与 .pro / .pro6。
- txt 不带样式。

## 第 4 步 翻译 / 拼音（可选，独立开关）

- 翻译目标语言多选，最多 4 种，默认英语。
- 原文在上，译文在下，需联网。
- 拼音只给汉字注音。
- 拼音位置可选：下方（默认）/ 上方 / 行尾括号。
- 声调可选带或不带，默认不带。
- 点「生成对照版」同步到分页预览。
- 改了歌词或拆页，要重新生成。

## 第 5 步 预览与导出

- 预览按页显示，点任意一页放大查看。
- 歌名页：歌名、歌手之外，可加译文行与拼音行。
- 歌名页四行均可按逐字、逐句、逐段设样式，拼音按音节计。
- 导出四选一：txt、.pro（ProPresenter 7）、.pro6（ProPresenter 6）、.pptx。
- 每页一幻灯片，段落名作分组。
- 多语译文和拼音行一并写入。
- 导出幻灯片为 1920×1080。
- 文本框铺满全屏，位置 0,0。
- 边距不为 0 时，按边距内缩。
- 每页只写文字行，页末不带空行。
- 旧已导入文件，需在 ProPresenter 内手动改，或重导出。
- 译文行 / 拼音行点一下变输入框，文字全选。
- 回车或失焦确认，Esc 取消。
- 修改写回对照版，并同步导出。
- 带拼音中文行：点拼音改整行拼音，点汉字改歌词且音节顺延。
- 生成后个别译文、拼音有误，不用重译，直接点改。

## 歌库

- 点「保存当前歌曲」，歌曲进歌库。
- 歌库按多级分类存放，分类可编辑、添加、删除。
- 库内按歌名与歌词内容搜索，简繁变体可互搜。
- 保存时记录该歌各页所用主题。
- 文件夹导出：按分类层级建文件夹，歌曲放入对应文件夹。
- 文件夹导出按该歌自身主题出主题文件，无主题旧歌不出主题文件。
- 文件夹导出同样先过版权确认。
- 手动同步：同步前先看同意说明，同意后才同步。
- 同步只覆盖歌库，冲突保留双方，删除不同步。
- 分享：选歌生成分享清单，先过版权确认，可作废，可转发。
- 导入与同步去重均以歌词为准，歌名只作辅助。

## 桌面版不同之处

- 快速识别语言数据、增强模型、拼音词库全部内置。
- 除翻译、云端识别、搜索外，离线可用。
- 语义建议面板：只标建议，不自动改。
- 非中日韩译文首字母大写。
- 段落标记识别覆盖多语言。
- 启动自动检测更新。
- 菜单里点检查更新，已是最新版弹「当前已是最新版」加版本号。
- 未取到版本或检查失败，弹真实原因。
- 启动后自动检查仍静默。
- 「编辑」菜单：撤销、重做、剪切、复制、粘贴、全选。
- 更新下载失败时，弹窗可直接下载安装包。
- 更新下载到系统下载文件夹，校验通过后先问一句再装。
- 点继续后同时打开安装向导和下载文件夹，按向导装到原来位置即可，旧版不用先卸载。

- 工具不编造，识别文本里没有的字不硬猜，搜索不到不编造候选。
- 导出以第 2 步校对后的歌词为准。
