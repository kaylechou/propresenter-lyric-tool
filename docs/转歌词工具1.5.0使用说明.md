# 转歌词工具 1.5.0 使用说明

## 1.5.0 新增

### 1. 导出全屏

- 导出幻灯片为 1920×1080。
- 文本框铺满全屏，位置 0,0。
- 边距不为 0 时，按边距内缩。
- 旧已导入文件，需在 ProPresenter 内手动改，或重导出。

### 2. 段落预设＋字号磅值

- 第 3 步新增：行高（倍）、行距（%）、段落间距（pt）、字符间距（pt）。
- 第 3 步新增：边距左 / 上 / 右 / 下。
- 第 3 步新增：描边（开关 / 宽度 / 颜色）。
- 第 3 步新增：阴影（开关 / 角度 / 偏移 / 模糊 / 透明度 / 颜色）。
- 字号可直接输入磅值，如 130pt。
- 磅值与百分比滑杆同步，60pt = 100%。
- 改动同步到第 5 步预览与 .pro / .pro6。
- txt 不带样式。

### 3. 导出空行清理

- 每页只写文字行。
- 页末不带空行。

### 4. 括号拼音去除

- 第 2 步「去括号拼音」默认开。
- 只有括号内全部为合法拼音音节，才连括号去掉。
- 可带声调符号或数字，如 qi、zhǔ、zhu3、lü、ping'an。
- 英文与说明括号保留。
- 覆盖：搜索拉取显示、智能清理、粘贴载入、分页预览与导出。

### 5. 译文 / 拼音点改

- 第 5 步卡片与放大查看内，译文行 / 拼音行点一下变输入框，文字全选。
- 回车或失焦确认，Esc 取消。
- 修改写回对照版，并同步导出。
- 带拼音中文行：点拼音改整行拼音，点汉字改歌词且音节顺延。
- 生成后个别译文、拼音有误，不用重译，直接点改。

### 6. 桌面手动检查更新反馈

- 菜单里点检查更新，已是最新版弹「当前已是最新版」加版本号。
- 未取到版本或检查失败，弹真实原因。
- 启动后自动检查仍静默。

### 7. 仓库地址置顶

- 使用说明顶部第一行即项目地址。
- 桌面版关于顶部第一行即项目地址。
- 桌面版安装包和更新说明在仓库的 Releases 里。
- 地址：https://github.com/kaylechou/propresenter-lyric-tool

## 核心流程

- 导入 → 清理 → 拆页 → 样式 → 翻译 / 拼音 → 导出 txt / .pro / .pro6。
- 搜索页签：填歌名搜歌词，选候选进校对。
- 云端识别：复杂谱面用大模型识谱，识别结果进第 2 步校对。

## 第 1 步 导入

- 粘贴歌词：一行一句，段落间空一行，段落名单独一行，点「载入并拆页」。
- 字幕文件 .srt / .lrc / .vtt / .ass：自动去时间轴和序号。
- 歌谱图片 / PDF：选识别引擎后点识别，自动整理进第 2 步。
- 全网搜索页签：填歌名，可填歌手、专辑。
- 多路并行搜索，候选并行拉取。
- 点卡片「查看并编辑」看全文改文字，点「生成分页预览」拆页。
- 结果自带括号拼音按音节去掉，英文保留。
- 点「换一换」再搜一批。
- 候选须与歌名或歌词句相关才列出。
- 搜不到不编造。

### 识别引擎

- 快速识别：本机，中英日韩等常用语言。
- 增强识别：本机，中文小字更准；网页版首次需联网下载模型，桌面版已内置。
- 云端识别：大模型识谱，复杂谱面用。
- 模型按提供方分组：Gemini、智谱、通义、硅基流动。
- Gemini 默认 gemini-3.5-flash-lite。
- 密钥按提供方分别保存，只存在本机设备。
- 识别出的歌名、歌手自动填入第 2 步空框，已有内容不覆盖。
- 云端没跑起来，按提示改用本地识别。

## 第 2 步 校对

- 对照原谱改错字，空行分段，段落名单独一行。
- 「谱面过滤＋分组」：去和弦行、简谱数字行、谱头信息，按标记或重复段分段。
- 「智能整理结构」：字幕用，去时间轴、序号、空行，重复段标副歌。
- 「智能清理」：只去汉字间空格、汉字与中文标点相邻空格；「去除标点」默认开。
- 「去括号拼音」：默认开，括号里符合拼音音节才去，英文不动。
- 「转简体 / 转繁体」：只转正文，歌名、歌手框不转。

## 第 3 步 拆页与样式

- 每页容量按行数或字数，默认 24 字，整行装页不拆行。
- 分段方式：按段落拆页或连续拆页。
- 段落名作标签或正文。
- 样式可调：字体、粗细、对齐、文字颜色、段落标签颜色。
- 另见 1.5.0 新增第 2 项：行高、行距、段落间距、字符间距、边距、描边、阴影、字号磅值。

## 第 4 步 翻译 / 拼音（可选，独立开关）

- 翻译目标语言多选，最多 4 种，默认英语。
- 原文在上，译文在下，需联网。
- 拼音只给汉字注音。
- 拼音位置可选：下方（默认）/ 上方 / 行尾括号。
- 声调可选带或不带，默认不带。
- 点「生成对照版」同步到第 5 步。
- 改了歌词或拆页，要重新生成。

## 第 5 步 预览与导出

- 预览按页显示，点任意一页放大查看。
- 导出三选一：txt、.pro（ProPresenter 7）、.pro6（ProPresenter 6）。
- 每页一幻灯片，段落名作分组。
- 多语译文和拼音行一并写入。

## 桌面版不同之处

- 快速识别语言数据、增强模型、拼音词库全部内置。
- 除翻译、云端识别、搜索外，离线可用。
- 语义建议面板：只标建议，不自动改。
- 非中日韩译文首字母大写。
- 段落标记识别覆盖多语言。
- 启动自动检测更新。
- 「编辑」菜单：撤销、重做、剪切、复制、粘贴、全选。
- 更新下载失败时，弹窗可直接下载安装包。

## 通用规则

- 工具不编造，识别文本里没有的字不硬猜，搜索不到不编造候选。
- 导出以第 2 步校对后的歌词为准。
