Pro Pages tool 1.8.0 使用说明

1.8.0 新增
1.8.0 新增

1. 清空范围自己选

- 清空时自己选范围，保留“全部恢复默认”。
- 换新歌词、换新歌名时自动清掉之前设置。
- 另有“沿用上一首设置”，默认不续用。
- 自己改的设置可存为自定义预设，名字可编辑。
- 换新时新增独立追加按钮，追加不重置。

2. 空白页不进导出

- 空白页只在预览里可见。
- txt、.pro、.pro6、.pptx 都不含空白页。

3. 运行日志不记歌词正文与搜索词

- 只记操作、环节、错误码、耗时。
- 保留 1000 条不变。
- 每条日志带日期（月-日 时:分:秒）。

4. 失败提示 10 秒自动消失

- 右下角小窗带真实问题与原因。
- 10 秒后自己消失。

5. 动态背景第一步

- 视频可导入，在预览里循环播放。
- 导出与自适应放下一步。

6. 字体颜色渐变

- 只支持两色，做 .pro、.proTheme、.pptx ＋预览。
- .pro6 不做。
- 角度＋色标列表，元素级＋逐段级两处。
- .proTheme 样例 298.0°。
- 教会电脑实机验。

7. 提示改纯色深底

- 全部主题的通知与失败提示改纯色深底。
- 静态说明提示保持偏淡，不改。

8. 共享歌库改名

- 中央贡献歌库改名“共享歌库”。
- 搜索里共享结果优先排。
- 共享歌库区域高亮。

9. 搜索全量出结果

- 三路全跑完再合并，不再找到就停。
- 直连加百度、Bing，四路并行。

10. Musixmatch 新口径

- 只走公开页抓取，无密钥、无登录。
- 公开页抓不到，点“跳过这一步”，直接进网页搜索。
- 迟到的结果不再追加。

11. 授权先测再存

- 其它网站按该站实际反馈决定授权方式。
- 不填就点跳过进下一步。
- 授权完先测可用、可用才保存在工具里。
- 登录过的站记在本机。

12. 分页预览新布局

- 上方大预览铺满、可直接改。
- 下方缩略图条，带页码、上一页、下一页。
- 单选多选，多选批量指定主题样式。

13. 界面主题选择器与视图切换（网页版）

- 顶栏“界面语言”下加“界面主题”下拉框。
- 5 个选项，默认经典暖纸，选择存本机、刷新不丢。
- 左下角悬浮按钮切手机版、电脑版。
- 电脑版按 1060 宽缩放，存本机，宽屏自动隐藏。

14. 顶部进度条跟界面主题

- 进度条底边细线颜色随 5 个界面主题走。

15. 更新下载双线路

- 点“立即下载”后按网络情况自动选线路，不用每次问。
- 顺序为 GitHub → 普鲁文第 9 分享 → 备用线路。

16. 字体启动缓存与 PWA

- 启动先显示缓存字体，再后台强制刷新。
- 新装字体能进来。
- 网页版安装按钮常显，点它按浏览器菜单安装。

17. 第二档登录可跳过（只桌面版）

- CCLI SongSelect、Melon、Bugs、Genie、Uta-Net、YouTube Music 登录弹窗新增“跳过这一步”。
- 点后关弹窗，该候选标记已跳过，登录按钮隐藏。
- 状态显示“已跳过{站名}，继续看下一个来源…”。

18. 拦截页跳过可自选

- 候选正文抓取弹拦截页提示时，取消改为跳过本候选。
- 跳过后的下一步由用户在设置里自选其一，默认回到候选列表。
- 回到候选列表：跳过后回列表，用户自己再点下一个。
- 自动取下一个候选：跳过后工具按顺序自动抓下一个。
- 设置项五语，存本机，刷新不丢。

19. 反馈预勾最近失败

- 反馈对话框打开时，默认预勾最近一条同类失败。
- 无记录时不勾。
- 用户可手动取消勾选。

1.7.0 新增（沿用）

1. 歌名页开关持久化

- 歌名页开关关掉再打开，仍是上次的选择。
- 刷新后选择不变，不用每次重设。

2. 歌曲自带样式

- 歌曲记录存下歌名页逐字、逐句、逐段样式。
- 从歌库载入时，用这首歌自己的样式。
- 库导出时，同样用歌曲自带样式。
- 老记录没有存样式时，按原有方式回退。

3. 推送收紧

- 推送候选并列时，收紧取舍。
- 只留更贴合的一项，不并列推出。

4. 空歌词跳过

- 没有歌词的候选直接跳过，不列出。
- 不占候选位置，不进校对。

5. 云共享扩围

- 云共享不再只限歌库。
- 当前文档、样式模板、主题文件、设置也可共享。
- 账号密钥不随共享发出。

6. 网络连接测试

- 工具内可测网络连接。
- 测连通、延迟、速度，分线路给出结果。

7. 自动轮询、手动代理与全路径路由

- 打开工具自动探测网络，关闭工具自动停止。
- 先走代理，再试普通连接，都不通走备用线路。
- 手动代理地址可在设置里填，桌面版可用。
- 手动地址优先于系统设置，系统设置优先于环境变量。
- 网络工具兼容：各类网络工具都适配，不逐个点名。
- 点按钮时按当前网络状态自动重排选路，原有线路保留，不删除。
- 覆盖搜索、翻译、拼音、识谱、同步、更新检查。
- 本地拼音与下载不走此规则。

8. YouTube 说明栏

- 搜索拉取时，可抓视频说明栏文字。
- 说明栏文字进校对，不编造。

9. 流媒体与两档歌词来源

- 流媒体与歌词提供商专用抓取：KKBOX、TIDAL、Spotify、Qobuz、Musixmatch、Genius。
- 两档来源都做，第一档直接抓取，第二档需登录授权。
- 登录授权弹相关页面，应用内弹窗共享会话，桌面版可用。
- 第二档登录可跳过（只桌面版）：6 站登录弹窗有“跳过这一步”，点后关弹窗、该候选标记已跳过、登录按钮隐藏。
- 弹窗前先提示：原因、官方域名核对、不存密码、关窗重试、会话保留与退出、需授权账号类型。

10. 桌面版进程说明

- 帮助与关于里写明四进程分工。
- 任务管理器里的 4 个进程是主进程、渲染进程、GPU 进程和工具进程的分工，这是正常现象，关主窗口会一起退，不要单独结束其中某一个，详细信息页看命令行可以对号。

11. 主题形状与多语分组

- 形状：矩形、直线、竖条、圆、菱形、框。
- 形状可设位置尺寸、旋转角、填充色与不透明度、描边宽与色、框边开关、圆角。
- 文本框可设填充色、内边距、行分隔符、两端对齐、行距档。
- 歌词 slide 可写 1–3 个文本框，原文、译文、拼音各绑一框。
- 分页预览与放大视图可拖动文本框设位置。
- 按五组预设文本位置：居中平衡、不重叠、安全区内，拿到就能用，不满意再拖动微调。
- 选主题时提示最多字数、行数；整体与每页设置时都提示。
- 版式要点：字号观众可见、原文行距不挤、行间间距与字号比例合适、铺满屏幕。
- 主题总数 34 个：现有 24 个＋新通用主题 10 个。
- 34 个主题按歌词分页、歌名页、原文、原文+多语翻译、原文+多语翻译+拼音编组，可多组。
- 名后备注用途，备注随语言翻译；主题名与组名随工具语言五语翻译。
- 新通用主题 10 个：下方半透明条、线框全幅、侧边竖条、中央圆、中央菱形、上下双杠、半透明框、上方半透明条、歌名页线框、歌名页双线。
- 只用通用名，不带背景，不内嵌字体。
- 背景不做，背景在 ProPresenter 里另配。
- 形状在 ProPresenter 内的显示效果待实机验证。

12. 共识高亮

1.6.0 新增（沿用）

1. 歌库分享机制

- 歌库里选歌，生成分享清单。
- 分享前先过版权确认，确认后才发出。
- 分享可作废，作废后对方不再能用这份分享。
- 分享可转发，转发时同样提示版权确认。
- 接收方导入时先预览，确认后再进歌库。

2. 去重与同步：歌词为主，歌名辅

- 去重以歌词本身为准，歌词相同即视为同一首。
- 同步索引新增歌词哈希，歌词一变，哈希跟着变。
- 同一首歌，歌词相同、歌名或歌手不同时，同步歌名与歌手。
- 不同歌曲，歌词不同时，跳过不覆盖。
- 导入时跳过的行，若歌名不同，同时显示两个歌名。
- 本地与同步之间，同样按歌词去重。
- 冲突时不单方面覆盖，保留双方内容。

3. 留置修复 7 项

- 单字标签修复：个别单字标签在语言切换时卡住，现已修好。
- 歌名页留置 3 项修复：文件夹导出按歌名页开关出歌名页；库导出歌名页条目带完整样式；从歌库载入歌曲时，歌名页显隐开关正确重置。
- 首次同步失败回退：首次同步推不上去时，按回退口径处理，不丢本地歌。
- 加载失败有界重试：加载失败时有限次数重试，不无限等待。
- 导入双显示扩展：导入跳过行歌名不同时，双歌名显示覆盖更多情形。
- 拉取提示双段：拉取结果提示分两段写清，先说结果，再说原因。
- 导出提示五语化：导出完成提示按当前界面语言显示。

4. 歌名页默认自动生成

- 歌名页开关默认开。
- 新歌自动建歌名页，不用手动选生成。
- 关掉开关可不贴歌名页，选择保留。
- 自动补建的歌名页，只写歌名与歌手。
- 译文与拼音不编造，没有就不写。
- 文件夹导出时，是否贴歌名页以该开关为准。

5. 液态玻璃界面

- 工具界面换为液态玻璃风格。
- 明亮浅色底，高对比可读。
- 只改工具界面样式层。
- 歌词渲染与导出结果不变。

6. K 全玻璃新图标

- 1.6.0 起，软件图标换为 K 全玻璃版。
- 明亮浅色，粗壮大图形，桌面上一眼能认出。
- 图标只换外观，功能不变。

7. 1.5.0 之后的其他变化

- 逐字、逐句、逐段样式：每段、每句、每字可设字体、字号、颜色、加粗。
- 主题样式：24 个主题样式可自由调用，拆页后每页可指定。
- .proTheme 导入：只导文字样式，不导位置、背景、形状。（1.6.0 时口径，1.7 见第 11 节）
- 主题文件一起导出：导出文本文件时，本文档各页用到的主题文件一并下载。
- .pptx 导出：导出四选一，txt、.pro、.pro6、.pptx。
- 歌库：保存、分类、导出导入共享，库内按歌名与歌词内容搜索。
- 歌库多级分类：分类可多级，可编辑、添加、删除。
- 歌库同步：手动同步，索引搜索拉取，冲突保留双方，删除不同步。
- 歌库文件夹导出：按多级分类层级建文件夹，歌曲放入对应文件夹。
- 界面五语：简体、繁体、英文、日文、韩文，静态文案全覆盖。
- 搜索简繁变体：繁体搜简体歌名、简体搜繁体歌名均可命中。

核心流程

- 导入 → 清理 → 拆页 → 字体 → 段落 → 样式 → 翻译 / 拼音 → 分页预览 → 歌库 → 导出 txt / .pro / .pro6 / .pptx。
- 搜索页签：填歌名搜歌词，选候选进校对。
- 云端识别：复杂谱面用大模型识谱，识别结果进第 2 步校对。

第 1 步 导入

- 粘贴歌词：一行一句，段落间空一行，段落名单独一行，点「载入并拆页」。
- 字幕文件 .srt / .lrc / .vtt / .ass：自动去时间轴和序号。
- 歌谱图片 / PDF：选识别引擎后点识别，自动整理进第 2 步。
- 全网搜索页签：填歌名，可填歌手、专辑。
- 三路全跑完再合并，不再找到就停；直连加百度、Bing，四路并行；候选并行拉取。
- 点卡片「查看并编辑」看全文改文字，点「生成分页预览」拆页。
- 结果自带括号拼音按音节去掉，英文保留。
- 点「换一换」再搜一批。
- 候选须与歌名或歌词句相关才列出。
- 搜不到不编造。
- 推送候选并列时收紧，只留更贴合的一项。
- 没有歌词的候选直接跳过。
- 视频说明栏文字可抓取进校对。
- 流媒体与歌词提供商有专用抓取，需登录的走应用内授权弹窗。
- Musixmatch 除外：只走公开页抓取，无密钥、无登录；抓不到点“跳过这一步”直接进网页搜索。
- 授权先测再存：填密钥或登录后，先测可用、可用才保存；登录过的站记在本机。
- 第二档登录可跳过（只桌面版）：6 站登录弹窗有“跳过这一步”，点后关弹窗、该候选标记已跳过。
- 拦截页跳过可自选：抓取弹拦截页提示时，取消改为跳过本候选；跳过后回候选列表或自动取下一个，设置里自选，默认回候选列表。

识别引擎

- 快速识别：本机，中英日韩等常用语言。
- 增强识别：本机，中文小字更准；网页版首次需联网下载模型，桌面版已内置。
- 云端识别：大模型识谱，复杂谱面用。
- 模型按提供方分组：Gemini、OpenAI、Claude、智谱、通义、硅基流动、DeepSeek、Kimi、豆包。
- Gemini 默认 gemini-3.5-flash-lite。
- 密钥按提供方分别保存，只存在本机设备。
- 识别出的歌名、歌手自动填入第 2 步空框，已有内容不覆盖。
- 云端没跑起来，按提示改用本地识别。

第 2 步 校对

- 清空范围自己选：保留“全部恢复默认”；换新歌词、换新歌名时自动清掉之前设置；“沿用上一首设置”默认关；自己改的设置可存为自定义预设，名字可编辑。

- 对照原谱改错字，空行分段，段落名单独一行。
- 「谱面过滤＋分组」：去和弦行、简谱数字行、谱头信息，按标记或重复段分段。
- 「智能整理结构」：字幕用，去时间轴、序号、空行，重复段标副歌。
- 「智能清理」：只去汉字间空格、汉字与中文标点相邻空格；「去除标点」默认开。
- 「去括号拼音」：默认开，括号里符合拼音音节才去，英文不动。
- 「转简体 / 转繁体」：只转正文，歌名、歌手框不转。

第 3 步 拆页与样式

- 每页容量按行数或字数，默认 24 字，整行装页不拆行。
- 分段方式：按段落拆页或连续拆页。
- 段落名作标签或正文。
- 样式可调：字体、粗细、对齐、文字颜色、段落标签颜色。
- 行高（倍）、行距（%）、段落间距（pt）、字符间距（pt）。
- 边距左 / 上 / 右 / 下。
- 描边（开关 / 宽度 / 颜色）。
- 阴影（开关 / 角度 / 偏移 / 模糊 / 透明度 / 颜色）。
- 字号可直接输入磅值，如 130pt。
- 磅值与百分比滑杆同步，60pt = 100%。
- 改动同步到分页预览与 .pro / .pro6。
- txt 不带样式。

- 字体颜色渐变：只支持两色，做 .pro、.proTheme、.pptx ＋预览；.pro6 不做。
- 动态背景：视频可导入，在预览里循环播放。

第 4 步 翻译 / 拼音（可选，独立开关）

- 翻译目标语言多选，最多 4 种，默认英语。
- 原文在上，译文在下，需联网。
- 拼音只给汉字注音。
- 拼音位置可选：下方（默认）/ 上方 / 行尾括号。
- 声调可选带或不带，默认不带。
- 点「生成对照版」同步到分页预览。
- 改了歌词或拆页，要重新生成。

第 5 步 预览与导出

- 分页预览新布局：上方大预览铺满、可直接改；下方缩略图条，带页码、上一页、下一页，单选多选，多选批量指定主题样式。
- 预览按页显示，点任意一页放大查看。
- 空白页不进导出：空白页只在预览里可见。
- 歌名页：歌名、歌手之外，可加译文行与拼音行。
- 歌名页四行均可按逐字、逐句、逐段设样式，拼音按音节计。
- 歌名页开关刷新后保留上次选择。
- 导出四选一：txt、.pro（ProPresenter 7）、.pro6（ProPresenter 6）、.pptx。
- 每页一幻灯片，段落名作分组。
- 多语译文和拼音行一并写入。
- 导出幻灯片为 1920×1080。
- 文本框铺满全屏，位置 0,0。
- 边距不为 0 时，按边距内缩。
- 每页写文字行与主题形状，页末不带空行。
- 格式下拉旁标明 .pro 为最新版本格式；.pro6 含形状时提示按非官方逆向资料实现、未经真机验证。
- 旧已导入文件，需在 ProPresenter 内手动改，或重导出。
- 译文行 / 拼音行点一下变输入框，文字全选。
- 回车或失焦确认，Esc 取消。
- 修改写回对照版，并同步导出。
- 带拼音中文行：点拼音改整行拼音，点汉字改歌词且音节顺延。
- 生成后个别译文、拼音有误，不用重译，直接点改。

歌库

- 点「保存当前歌曲」，歌曲进歌库。
- 歌库按多级分类存放，分类可编辑、添加、删除。
- 库内按歌名与歌词内容搜索，简繁变体可互搜。
- 保存时记录该歌各页所用主题。
- 文件夹导出：按分类层级建文件夹，歌曲放入对应文件夹。
- 文件夹导出按该歌自身主题出主题文件，无主题旧歌不出主题文件。
- 文件夹导出同样先过版权确认。
- 手动同步：同步前先看同意说明，同意后才同步。
- 同步只覆盖歌库，冲突保留双方，删除不同步。
- 分享：选歌生成分享清单，先过版权确认，可作废，可转发。
- 导入与同步去重均以歌词为准，歌名只作辅助。
- 歌库载入与库导出用歌曲自带样式，老记录回退。
- 云共享扩至当前文档、样式模板、主题文件、设置，密钥不随共享发出。
- 共享歌库：原名中央贡献歌库，1.8.0 起改名“共享歌库”；共享歌库区域高亮。

桌面版不同之处

- 快速识别语言数据、增强模型、拼音词库全部内置。
- 除翻译、云端识别、搜索外，离线可用。
- 语义建议面板：只标建议，不自动改。
- 非中日韩译文首字母大写。
- 段落标记识别覆盖多语言。
- 启动自动检测更新。
- 菜单里点检查更新，已是最新版弹「当前已是最新版」加版本号。
- 未取到版本或检查失败，弹真实原因。
- 启动后自动检查仍静默。
- 「编辑」菜单：撤销、重做、剪切、复制、粘贴、全选。
- 更新下载失败时，弹窗可直接下载安装包。
- 更新下载到系统下载文件夹，校验通过后先问一句再装。
- 点继续后同时打开安装向导和下载文件夹，按向导装到原来位置即可，旧版不用先卸载。

- 工具内可测网络连接，给出连通、延迟、速度结果。
- 打开工具自动探测网络，关闭工具自动停止。
- 手动代理地址可在设置里填，手动优先于系统，系统优先于环境变量。
- 帮助与关于里写明四进程分工。
- 任务管理器里的 4 个进程是主进程、渲染进程、GPU 进程和工具进程的分工，这是正常现象，关主窗口会一起退，不要单独结束其中某一个，详细信息页看命令行可以对号。

- 弹出页默认隐藏菜单，按 Alt 可唤出；外链仍在应用内打开。

- 更新下载双线路：点“立即下载”后按网络情况自动选线路，不用每次问；顺序为 GitHub → 普鲁文第 9 分享 → 备用线路。
- 字体启动缓存：启动先显示缓存字体，再后台强制刷新；新装字体能进来。
- 运行日志：帮助菜单里点“运行日志”查看；只记操作、环节、错误码、耗时，不记歌词正文与搜索词；留 1000 条；每条带日期。
- 失败提示：任何操作出问题，右下角浮出小窗，带真实问题与原因；10 秒自动消失。
- 提示纯色深底：全部主题的通知与失败提示都用纯色深底。
- 界面主题 5 个：活力粉青、科技冰蓝、经典暖纸、时尚紫罗兰、液态玻璃；桌面版在视图 → 主题里切，网页版在顶栏“界面主题”下拉框里切，默认经典暖纸，选择会记住；网页版左下角悬浮按钮切手机版、电脑版。
- 网页版安装按钮常显，点它按浏览器菜单安装。
