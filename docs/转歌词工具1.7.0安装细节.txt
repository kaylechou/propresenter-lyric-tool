Pro Pages tool 1.7.0 安装细节（Windows 与 Mac）

下载地址：https://github.com/kaylechou/propresenter-lyric-tool/releases/tag/v1.7.0

一、下载哪个文件

- Windows：lyric-tool-setup-1.7.0.exe（安装器，推荐）
  或 lyric-tool-portable-1.7.0.exe（便携版，免安装，直接运行）
- Mac：M 系列芯片（M1 / M2 / M3 / M4）下 lyric-tool-mac-applesilicon.zip
  Intel 芯片下 lyric-tool-mac-intel.zip
  分不清芯片：点左上角苹果标志 → 关于本机，看“芯片”一栏。

二、Windows 安装

1. 双击安装器 → 选择安装位置 → 下一步完成。
   1.5.0 起安装器可选路径；1.4.1 及以前是默认装到系统用户目录，改不了。
2. 弹出“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
   软件未签名，第一次都会这样，点一次即可。
3. 便携版不用安装，解压后双击就能用，换电脑拷走就行。
4. 更新：工具菜单点“检查更新”→ 下载到系统下载文件夹 →
   校验通过后先问一句再装 → 点继续后同时打开安装向导和下载文件夹，
   按向导装到原来位置即可，旧版不用先卸载。

三、Mac 安装（重点：终端命令）

1. 下载对应芯片的 zip，解压得到 .app：
   M 系列：转歌词-AppleSilicon.app
   Intel：转歌词-Intel.app

2. 先清隔离标记（关键一步）。
   浏览器下载的文件都带隔离标记，不清就报“已损坏”。
   打开“终端”（Spotlight 搜“终端”），输入：

   xattr -cr /Applications/转歌词-AppleSilicon.app

   说明：
   - xattr 是清标记的命令，-c 是清除，-r 是连同 .app 里面一起清。
   - 命令要对准解压出来的 .app 本人，不要对 zip 包用，
     也不要对着装它的文件夹用。
   - 路径换成你实际的：.app 在哪，路径就写哪。
     上面那行是假设 .app 放在“应用程序”文件夹里。
   - 偷懒办法：先在终端敲好 xattr -cr 加一个空格，
     再把 .app 从访达里拖进终端窗口，路径会自动填好，回车。
   - 路径里有空格，手打要在整个路径外加英文双引号，拖入法最稳。
   - 回车后没有任何输出就是成功，不用再做什么。
   - 重复下载的文件名后面会带 -2，解压出来的 .app 名也可能跟着变，
     对准实际名字再敲。

3. 再右键打开。
   第一次不要双击，用右键（或按住 Control 点按）.app →
   点“打开”→ 在弹出框里再点“打开”。
   软件未签名，右键打开是给未签名应用留的口子。
   之后双击就能正常打开。

4. 如果已经点过“已损坏”提示：
   先把这个 .app 删掉，重新解压一份，
   再按第 2、3 步（清标记、右键打开）走一遍。
   已经点过损坏提示的旧 .app 就不要再用了。

四、常见问题

- Windows 装完找不到图标：去开始菜单搜“转歌词”，或看安装时选的路径。
- Windows 安装器打不开：先确认下载完整，再按“更多信息 → 仍要运行”。
- Mac 提示“无法验证开发者”：按上面第 3 步右键打开，不要双击。
- Mac 提示“已损坏，无法打开”：按上面第 2 步清标记；
  已经点过损坏提示的，先删重解压再清。
- Mac 终端输完命令没反应：没有输出就是成功，直接右键打开就行。
- Mac 装错芯片的包：M 系列机器装了 Intel 包也能跑，但最好换回对应芯片的包。
- 更新后打不开：重装一遍新版安装包即可，旧版不用先卸载。

五、桌面版进程与网络

- 任务管理器里的 4 个进程是主进程、渲染进程、GPU 进程和工具进程的分工，这是正常现象，关主窗口会一起退，不要单独结束其中某一个，详细信息页看命令行可以对号。
- 进程分工说明在帮助与关于里可看。
- 工具内可做网络连接测试，给出连通、延迟、速度结果。
- 打开工具自动探测网络，关闭工具自动停止。
- 手动代理地址可在设置里填，手动优先于系统，系统优先于环境变量。
- 弹出页默认隐藏菜单，按 Alt 可唤出；外链仍在应用内打开。
- 更新下载有进度条，可取消；双源并行分段，自适应分段；后台预取。

六、主题形状与分组

- 主题可带形状：矩形、直线、竖条、圆、菱形、框；可设位置尺寸、旋转角、填充色与不透明度、描边宽与色、框边开关、圆角。
- 文本框可设填充色、内边距、行分隔符、两端对齐、行距档。
- 歌词 slide 可写 1–3 个文本框，原文、译文、拼音各绑一框。
- 分页预览与放大视图可拖动文本框设位置；按五组预设文本位置，拿到就能用。
- 选主题时提示最多字数、行数；整体与每页设置时都提示。
- 主题总数 34 个：现有 24 个＋新通用主题 10 个；按五组编组，可多组；名后备注用途，备注随语言翻译；主题名与组名随工具语言五语翻译。
- 新通用主题 10 个：下方半透明条、线框全幅、侧边竖条、中央圆、中央菱形、上下双杠、半透明框、上方半透明条、歌名页线框、歌名页双线；只用通用名，不带背景，不内嵌字体。
- 背景不做，背景在 ProPresenter 里另配。
- 形状在 ProPresenter 内的显示效果待实机验证。
- .pptx、.pro、.pro6 导出均可带主题形状；无形状主题输出不变。
- .pptx 叠放顺序：形状在下，歌词框在中，下一句框在上；菱形以旋转矩形呈现。
- 格式下拉旁标明 .pro 为最新版本格式；.pro6 含形状时提示按非官方逆向资料实现、未经真机验证。
