# Pro Pages tool

把歌词文本、歌谱图片、字幕文件，整理成 ProPresenter 可直接导入的分页歌词。只要歌词，不要音符。

## 用法

顶部九胶囊切换模块：导入歌词／校对歌词／拆页／字体／段落／样式／翻译·拼音／分页预览／歌库，粘贴载入、字幕导入、识别完自动切到校对，生成对照版后自动切到分页预览。页首标题栏右侧有「使用说明」按钮，点开是八节短句版使用说明。

### 1. 导入

![导入](docs/images/step-import.png)

- 粘贴歌词文本，或打开 `.txt` 文件（歌名自动取文件名）
- 歌谱图片、PDF 也能识别，只取歌词，不认音符
- 字幕文件 `.srt` / `.lrc` / `.vtt` / `.ass` 直接导

### 2. 校对与智能整理

![校对与智能整理](docs/images/step-organize.png)

- 自动去掉时间轴、序号与句间空行
- 重复段标副歌，其余依次标主歌；晚出现的独立段标桥段，结尾短段标尾声
- 一键「智能整理结构」，段落名可再改
- 智能清理：只去汉字间空格，英文、韩文词间空格原样保留
- 去括号拼音：第 2 步默认开启的开关，只有括号内全部为合法拼音音节才连括号去掉，英文与说明括号保留
- 繁简互转：校对区转简体、转繁体一键全文原地互转，只转歌词正文，歌名／歌手框不动，空行分段与段落名行位置不变；歌词菜单同步有转简体、转繁体两项
- 歌谱整理：一键去掉和弦行、简谱数字行与谱头信息，按主歌/副歌/桥段等段落分组；谱面上下两行歌词的，开「双行歌词」再整理，会按两遍拆成主歌一、主歌二
- 谱头清除：第一句真歌词前整段去掉，专辑/原曲/年份/拉丁乱码行在正文任何位置也删
- 副歌合并：两遍词不同的副歌按演唱顺序排进同一副歌段
- 红清单：含汉字又删过拉丁乱码的行，整理后下方红色清单列出原行、删掉的乱码、删完的样子
- 断句规则：先按标点断句再去标点，碎行合并看标点
- 纯粘贴分段标注与可疑行标记：粘贴的歌词也能分段标注，可疑行单独标记
- 段落标记多语言识别：日韩＋世界常规语言段落词都能认，段落名按标记语言输出（`[Chorus]`→Chorus、`[サビ]`→サビ、`[후렴]`→후렴，无标记推断用歌中已出现标记的语言，全首无标记按歌词主导语言）
- 歌谱识别语言 33 项（默认多语言混合），识别前预处理（放大、灰度、对比增强、整块文本模式保行序）
- 识别引擎双选：快速识别（默认）即开即用；增强识别 · PaddleOCR 本机识别、图片不上传；33 门识别数据与 PaddleOCR 模型已全部内置本机，离线可用，失败自动回退快速识别
- 云端识别：大模型识谱，谱面复杂、快速／增强认不准时用；模型按提供方分组（Gemini、智谱、通义、硅基流动），密钥按提供方分别保存、只存本机，失败自动回退本地识别；云端识别出的歌名、歌手自动填入歌名／歌手框（已有内容不覆盖）；识别走两路，优先直连各家接口（桌面走主进程，网页直接调接口），只有发不出去才自动切换，提供方拒答即最终结论不切换
- 全网搜索（第 1 步第三页签）：填歌名（可再填歌手、专辑）搜索；流程内自动轮询（百度→Bing→DuckDuckGo→Google，凑满 6 条候选即停），无手动开关；候选点「查看并编辑」先看全文，结果框可直接改文字，点「生成分页预览」即用改后歌词拆页；换一换、重新搜索、相关性门槛（无关结果滤掉）、各路结果明细、简繁双搜繁转简、歌名英日韩轮询；搜不到不编造；搜索多路并行、候选并行预拉，备用线路侧四引擎并查，总体更快
- 搜索三级路由：直连→备用线路补位→免费代理兜底；抓取按响应头与 meta 判定编码解 GBK/Big5，实体单遍全量解码，损坏内容自动降级重抓；桌面版直连走主进程本机网络（不受浏览器跨域限制），本机能直达的站不再绕备用线路
- 共识高亮：结果出齐后比对各来源文本，高亮推荐复制文本（只作推荐，不静默覆盖）
- 说明栏与专用抓取：视频说明栏文字可抓取进校对；流媒体与歌词提供商有专用抓取，需登录的走应用内授权弹窗（登录只作兜底，桌面版）
- 推送收紧、空歌词跳过：候选并列时只留更贴合的一项；没有歌词的候选直接跳过
- 谱头粘连行过滤：速度数字与标题粘连成一行的谱头行不再漏进歌词

### 3. 拆页与样式设置

![拆页与样式设置](docs/images/step-style.png)

- 按段落、行数或字数拆页（字数 6–80 可调，默认 24，整行装页不拆行）
- 字体（微软雅黑 / 黑体 / 宋体 / 楷体 / Arial）、字号直接输入具体磅值（全页统一，与百分比滑杆同步，60pt=100%）、粗细、对齐、文字颜色；段落预设：行高倍数、行距百分比、段落间距、字符间距、边距（左/上/右/下）、描边（开关/宽度/颜色）、阴影（开关/角度/偏移/模糊/透明度/颜色）
- 每个段落标签的颜色逐个改（默认主歌蓝、副歌粉红）
- 改动同步进预览与 `.pro` / `.pro6` / `.pptx`
- 导出文本框铺满 1920×1080（边距为 0 时），导出无页末空行
- 歌名页：开关跨刷新保留；歌曲记录存歌名页逐字/段落样式，库导出用歌曲自带样式（老记录回退）
- 主题：34 个主题（24 个现有＋10 个新通用），按歌词分页／歌名页／原文／原文+多语翻译／原文+多语翻译+拼音编组；主题名与组名随工具语言五语翻译；主题全元素适配（线条方框等元素、工具内预览可编辑、原文译文拼音任意摆放）；分页预览可拖动文本框设位置；选主题与设置时提示容量
- 版式：字号观众可见、原文行距不挤、行间间距与字号比例合适、铺满屏幕
- 同页下一句（默认关）、液态玻璃独立开关（默认关，只改样式层）

### 4. 翻译 / 拼音（可选）

- 两个独立开关：只翻译、只拼音、两者都选、两者都不选
- 翻译：36 种语言多选 + 自定义语言代码，最多 4 种（默认英语），逐页逐语言翻译，分页不变
- 翻译跳过同语言行：某行本身就是目标语言时跳过该行该目标语言的翻译，避免同页出现两句相同歌词
- 翻译首字母大写（中日韩、阿拉伯、希伯来、印地、泰语除外），预览与 txt/.pro/.pro6 一致
- 译文/拼音点改（1.5.0 修复）：预览卡片与放大查看内译文行、拼音行点一下变输入框，回车或失焦确认、Esc 取消，改动同步导出，重新生成对照版会覆盖手动修改
- 拼音：逐字注音、只注汉字，位置可选中文行下方 / 上方 / 行尾括号，声调默认不带
- 翻译走免费接口，无需 key；歌词机翻需校对
- 简繁短语表：简繁转换先用短语表，按需全量/短语转换（加载失败退回原有转换）

### 5. 预览与导出

![预览与导出](docs/images/step-export.png)

- 16:9 分页预览，点页放大看
- 导出四选一：`txt`（纯文本，不带样式）、`.pro`（ProPresenter 7）、`.pro6`（ProPresenter 6）、`.pptx`
- 段落名作分组，标签颜色一并写入
- 导出带主题形状（.pro6 按非官方逆向资料实现、未经真机验证，格式下拉旁标明 .pro 为最新版本格式）
- 歌名页四行（歌名、歌手、译文、拼音）均可逐字/逐句/逐段设样式

### 6. 网络、共享与反馈

- 网络连接测试：顶栏一键测直连与备用线路、GitHub 同步、9 家 AI 端点，给出连通、延迟、速度
- 自动轮询：开工具即探、关工具即停；先网络工具、再直连、后备用线路；手动代理地址（桌面版），手动>系统>环境变量；覆盖搜索、翻译、拼音、识谱、同步、更新检查
- 中央共享歌库：同意共享后去重，工具内直接可搜；全网搜索亦搜中央库（中央结果优先）；同意可随时撤回
- 云共享扩围：云共享扩至当前文档、样式模板、主题文件、设置（密钥与 PAT 不进载荷）
- 反馈：帮助菜单与主界面反馈按钮；内容必填、截图最多 3 张；提交后凭本地编号查状态与回执

## 桌面版说明

- Windows、Mac 桌面版除翻译、云端识别、搜索需联网外，全部离线可用（33 门识别数据与 PaddleOCR 模型已内置本机）
- 安装包未签名：Windows 首次运行若弹出 SmartScreen，点“更多信息”→“仍要运行”；Mac 首次打开请右键 → 打开，仍被拦截时到“系统设置 → 隐私与安全性”点“仍要打开”
- Mac 芯片查看方法：左上角苹果菜单 → 关于本机 → 芯片一栏
- 启动自动检测更新：打开软件后自动检查新版本，有新版会弹窗提示，可一键下载更新（Windows 下载并校验通过后会先问是否继续安装，确认后打开安装程序并在向导里选安装路径，同时打开下载文件夹，装完后可自行决定是否删除安装包，Mac 下载后请解压替换旧版）；手动点菜单「检查更新」时，已是最新版、未取到版本、检查失败都会弹提示，自动检查仍静默；更新检查与下载先走直连、直连不通回备用线路，8 连接分段下载、断点续传，更新弹窗显示对应版本的发版正文；备用线路繁忙时延迟重试，两路失败弹窗显示真实原因并可点“直接下载最新版”用浏览器直接下载对应安装包
- 关于置顶：桌面版「关于」顶部固定显示 GitHub 仓库地址
- 下载完整性校验：更新下载完成后自动验尺寸＋SHA256（对照表 SHA256SUMS.txt），不一致重下最多 3 次，仍不一致不打开并报错
- 语义纠错建议：本地词典＋搭配检查，只标建议、不自动改，接受才改行并同步导出
- 云端识别：Gemini（免费档）或智谱／通义／硅基流动，各平台建密钥、只贴工具对应提供方令牌框、只存本机；识别优先直连各家接口（桌面走主进程），直连不通自动切换，提供方拒答不切换；失败回退本地识别
- 流量全加密：所有对外请求一律 HTTPS；域名加密 ECH，不改系统 DNS、不覆盖代理设置
- 下载五项：进度条、可取消、双源并行分段、自适应分段、后台预取
- 弹出页默认隐藏菜单（按 Alt 唤出，外链仍应用内打开）
- 四进程：任务管理器里的 4 个进程是主进程、渲染进程、GPU 进程和工具进程的分工，属正常现象，关主窗口一起退
- 图标换为 E2 强对比版

## 导入 ProPresenter

- `txt`：导入时选 Paragraph Break、1 delimiter per slide
- `.pro`：ProPresenter 7 直接导入；`.pro6`：ProPresenter 6 直接导入
- 段落名作分组，标签颜色随分组写入

## 注意

- 歌词内容以第 2 步校对为准，导出前请对照原文看一遍
- 翻译是机翻，重要场合请校对；多音字按常用读音注音，重要场合请再检查
